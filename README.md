# A little romantic journey ❤️

A complete static website for GitHub Pages. Open `index.html` locally to preview it. The site includes your supplied photographs, nine balloon reveals, four gated gifts, animations, and an original gentle instrumental loop that starts when a visitor taps a button. No build step is required.

## Publish on GitHub Pages

1. Create a new public GitHub repository (for example, `our-little-journey`).
2. Upload **the contents of this folder** (`index.html`, `style.css`, `script.js`, and the `assets` folder) to the root of the repository, then commit.
3. In repository **Settings → Pages**, select **Deploy from a branch**, branch **main**, folder **/(root)**, then save.
4. Your link will be `https://YOUR-USERNAME.github.io/our-little-journey/`. It may take a few minutes to appear.

The music is generated in the visitor's browser and begins only after a tap because browsers block automatic sound. The site uses Google Fonts when connected, with local fallback fonts. All photos and site functionality are bundled and work without an external service.
