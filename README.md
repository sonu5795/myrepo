# For Aparna, Always ✨

A self-contained static surprise site from Sonu to Aparna. It has an opening envelope, five interactive stars, a swipeable photo collection, a personal letter, a hold-to-reveal finale, and soft original instrumental music generated in the browser. The music begins after a visitor interacts, as browsers restrict autoplay with sound.

## Publish on GitHub Pages

1. Create a public GitHub repository, for example `for-aparna`.
2. Extract this ZIP and upload **its contents** (`index.html`, `style.css`, `script.js`, and the `assets` folder) into the repository root. Commit the files.
3. Go to **Settings → Pages → Build and deployment**. Choose **Deploy from a branch**, select **main** and **/(root)**, then save.
4. Visit `https://YOUR-USERNAME.github.io/for-aparna/` after deployment finishes.

You can preview it by opening `index.html` locally. The bundled photos and music need no hosting beyond GitHub Pages. Google Fonts are optional; system font fallbacks are included.

## Personalizing

Edit the letter text and headings in `index.html`; edit star messages and photo captions in `script.js`. Keep the `assets` folder next to the three site files.
