# For Aparna — Midnight, A Little More Us

Black background, ivory text, gold fairy lights and rose accents. Includes the heart-sealed envelope, all eight original messages and thirteen photos in the same order, background Tum Mile music, chapter teasers, live letters, keepsake pocket, eight glowing memory lights, imagined future moments, virtual teddy hug, Aparna’s A star constellation, heart fireworks, and three little letters for when she misses you.

## Open locally
Extract all files, open Aparna-Keepsake, and double-click index.html. Keep the assets folder with the other files. No installation or online dependency is needed.

## GitHub Pages
Upload the CONTENTS of Aparna-Keepsake to the repository root. Settings → Pages → Deploy from a branch → main → / (root) → Save. Use the website URL GitHub provides.

Music starts after an opening-button tap and loops throughout. Top-right button pauses/resumes it. Letters offer pause and full text. All chapters remain directly accessible; teasers invite continuing without locking anything. Each opened letter lights a keepsake in the pocket; all keepsakes can be explored at any time. The eight lights after the last memory reveal special notes. Three extra letters appear below the final photograph. Reduced-motion settings are respected.

Original photo order: chapter 1 = 1; 2 = 2–3; 3 = 4–5; 4 = 6; 5 = 7–8; 6 = 9; 7 = 10–11; 8 = 12–13. Original messages and audio are preserved. Faces are not retouched.
