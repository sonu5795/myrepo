# Every Little Moment of Us — Aparna & Sonu

## Open locally
Double-click index.html. The website has no installation or internet dependency. Keep all the files and the assets folder together.

## Publish on GitHub Pages
1. Extract this ZIP.
2. Create a GitHub repository and upload the contents of this folder (index.html must be at the repository root). Keep the assets folder intact.
3. In repository Settings → Pages, choose Deploy from a branch, then main and / (root), and Save.
4. Use the website address shown by GitHub Pages after deployment.

Music begins after the opening button or music button is tapped; browsers require an interaction before audible playback. It loops throughout the story. The music button pauses or resumes it.

Each chapter offers live writing, a full-letter button, pause/resume, photo enlargement, and a surprise note. Chapter numbers and the memory map allow revisiting any chapter. The finale launches animated fireworks and the love message. Reduced-motion device settings are respected.

All eight supplied messages are preserved, excluding the instruction about photo order embedded in content 8. Photos follow the supplied attachment order: chapter 1 = photo 1; chapter 2 = photos 2–3; chapter 3 = photos 4–5; chapter 4 = photo 6; chapter 5 = photos 7–8; chapter 6 = photo 9; chapter 7 = photos 10–11; chapter 8 = photos 12–13.

The originals were not edited; website copies were resized proportionally and saved as JPEG for loading speed. Faces were not retouched. The supplied Tum Mile audio is included.
