# For Aparna — A Little More Us

A rose-and-ivory keepsake with a heart-sealed envelope, eight memory chapters, thirteen ordered photos, live-writing full letters, little chapter surprises, a future-moments garden, a virtual teddy hug, and a night-sky finale with Aparna’s A constellation and heart-shaped fireworks. The look, original eight messages, photo order and Tum Mile music are retained.

## Open
Extract the ZIP, open the Aparna-Keepsake folder, and double-click index.html. Keep files and the assets folder together. No installation or internet connection is required for the local website.

## The surprises
Tap the opening button to start music and reach the sealed envelope. Tap its heart, then enter the memories. Each chapter has a full live-writing letter, pause/resume and full-text controls, photo enlargement and a small surprise note. After chapter eight, explore four imagined moments together, enjoy a little virtual hug, and light up the sky. Look for the extra note beneath the last photograph. The memory album and chapter buttons revisit earlier pages.

Music continues across pages and loops; the top-right music button pauses/resumes it. Reduced-motion preferences are respected.

## GitHub Pages
Upload the CONTENTS of Aparna-Keepsake to your repository root, including the assets folder. Settings → Pages → Deploy from a branch → main → / (root) → Save. GitHub provides the deployed website URL.

Chapter 1: 1; chapter 2: 2–3; chapter 3: 4–5; chapter 4: 6; chapter 5: 7–8; chapter 6: 9; chapter 7: 10–11; chapter 8: 12–13. Website image copies are resized proportionally; faces are not retouched.
